Tello Drone Control

Use the following keys to control the drone:

  • Arrow Up: Move forward
  • Arrow Down: Move backward
  • Arrow Left: Move left
  • Arrow Right: Move right
  • W: Move up
  • S: Move down
  • A: Rotate counter-clockwise
  • D: Rotate clockwise
  • T: Take off
  • L: Land
